# 配置热加载（config-hot-reload-java）

在进程运行期自动发现本地配置文件变更并原子生效，读取方任何时刻只能看到某个
自洽的完整版本；校验失败保持上一可用版本，支持差异输出与一键回退。

## 架构

```
本地 properties 文件 ──> FileConfigSource（容忍半写/连写）
                              │
              ConfigFileWatcher（WatchService 自动发现变更）
                              │ 变更通知（防抖合并）
                              ▼
                  HotReloadConfigManager
                    ├─ 多来源按优先级合并 + 出处追踪
                    ├─ ConfigValidator 校验候选版本
                    ├─ AtomicReference<ConfigSnapshot> 原子发布
                    ├─ ConfigDiff 差异计算
                    └─ 回退到最近已生效版本
                              │
                              ▼
              ConfigController（REST：查询/重载/回退/差异）
```

## 重载语义

- **原子生效**：当前版本保存在 `AtomicReference` 中，快照（`ConfigSnapshot`）
  不可变。重载只替换引用，读操作零锁、零阻塞；任何时刻读到的都是某个完整
  版本，绝不出现新旧字段混合。
- **半写容忍**：文件被整体覆盖或快速连续写入时，`FileConfigSource` 会检测
  不完整内容（解析失败、出现无分隔符的残行、读取期间文件仍在变化）并重试，
  重试耗尽后判定该来源失败，**不会**让写了一半的内容生效。
- **失败保护**：运行期任何来源读取失败或校验不通过，本次重载整体被拒绝，
  上一可用版本继续服务，不存在半生效状态；错误信息定位到具体来源与配置项。
  （启动首次加载例外：缺失的来源被容忍，可用来源先生效。）
- **无变化不重载**：合并结果与当前版本内容一致时不产生新版本，也不产生
  虚假的变更记录。
- **防抖与重试**：短时间内的反复变更按 `debounce` 窗口合并为一次重载；
  失败按 `max-retries` / `retry-interval` 重试，整体受 `max-wait` 约束，
  超时放弃本轮，来源长时间不可用或频繁抖动时不会忙循环。
- **回退**：`rollback()` 恢复到最近一次已生效版本；回退与重载在同一把锁上
  串行，并发发生时结果确定，中间状态对读取方不可见。

## 优先级规则

- 多个来源按 `config.reload.sources` **列表顺序**排列，越靠后优先级越高，
  高优先级来源的同名键覆盖低优先级。
- 单个来源缺失、损坏或暂时不可读不影响其他来源的读取；每个生效键的出处
  记录在快照的 `provenance` 中（`GET /config` 可见）。
- 运行期来源失败会导致本次重载被拒绝（保持旧版本），以避免把"来源暂时
  不可读"误判为"配置项被删除"。

## 可用配置项（前缀 `config.reload`）

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `sources[i].path` | — | 本地 properties 文件路径 |
| `sources[i].name` | 文件名 | 来源名称，用于日志与出处追踪 |
| `debounce` | `200ms` | 防抖窗口，合并短时间内的连续变更 |
| `max-retries` | `3` | 重载失败后的重试次数 |
| `retry-interval` | `500ms` | 重试间隔 |
| `max-wait` | `5s` | 一次重载（含重试）的最长等待时间 |
| `watch-enabled` | `true` | 是否启用文件变更自动监听 |

## REST 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/config` | 当前生效版本：版本号、全部键值、每个键的来源 |
| GET | `/config/{key}` | 单个键的值、来源与版本 |
| GET | `/config/diff` | 最近一次重载/回退的差异（新增/删除/改动） |
| POST | `/config/reload` | 手动触发一次重载 |
| POST | `/config/rollback` | 回退到最近一次已生效版本 |

重载结果 `status`：`APPLIED`（新版本生效）、`NO_CHANGE`（内容无变化）、
`REJECTED`（失败，保持旧版本，`errors` 定位到来源与配置项）、
`ROLLED_BACK`（已回退）。
